# 2DBrotato

一个仿吸血鬼幸存者 / Brotato 风格的俯视角自动射击游戏，纯前端单 HTML + Canvas 实现，无任何依赖。

## 玩法

- WASD / 方向键移动，武器自动瞄准射击
- 在 30 秒敌潮中幸存 → 进入商店购买枪械/道具 → 进入下一波
- 共 30 波，每 10 波遭遇随机 Boss
- 第 30 波通关胜利；中途阵亡结算

## 武器（6 种）

| 武器 | 每级特殊效果 |
|------|-------------|
| 手枪 | 命中后按几率分裂出 2 颗 1.5× 子弹 |
| 冲锋枪 | 几率额外射出 1 颗随机其他武器子弹 |
| 霰弹枪 | 每 2 级 +1 弹丸，每级散布 -5% / 射程 +15% |
| 狙击枪 | 曳光弹；每级暴击率 +3%，暴击 3 倍伤害 |
| 激光枪 | 每级子弹体积 +25%，发光光晕 |
| 火箭筒 | 范围爆炸；每级爆炸范围 +20%（最大 5 倍）|

## 道具（8 种）

护甲板 / 大心脏 / 浓缩咖啡（攻速上限 +100%）/ 跑鞋 / 磁铁 / 哑铃 / 再生叶 / 幸运草

## Boss（3 种，每 10 波随机刷新）

- 巨兽：蓄力冲撞（白闪虚线预告方向）
- 召唤者：保持距离，周期召唤小怪
- 弹幕领主：16 向环弹 + 3 连瞄准弹（发射前 0.3 秒预警环/虚线）

## 商店机制

- 4 张随机商品卡，重复购买同级武器升级 Tier
- 一键购买（Enter）/ 刷新（空格）/ 单卡锁定（保留到下一波）
- 同名道具每买 1 个，价格 ×1.15；每波商店价格复利 ×1.15

## 难度公式

- 普通敌人血量：每波 ×(1 + 15% + 0.5%×道具数)，第 11/21 波翻倍跳跃
- 每击败 1 个 Boss，全场敌人血量 ×1.5（跨波持续）
- Boss 血量：基础 3600 × 敌人血量倍数

## 数据看板

`dashboard.html` 在浏览器打开后，从 localStorage 读取最近 30 局存档，展示：

- 波次耗时柱状图
- 普通敌人/Boss 平均击杀时间曲线
- 玩家数值成长曲线（伤害、攻速、移速、护甲、回复等）
- 敌人 HP 倍数曲线、武器 Tier 成长曲线
- 逐波数据表格
- 支持刷新 / 清空 / 导入 / 导出 JSON

## 文件结构

```
2DBrotato/
├─ index.html          游戏入口
├─ dashboard.html      数据看板
├─ js/
│  ├─ data.js          全局状态、武器/道具/敌人/Boss 定义、数值公式、运行日志
│  ├─ audio.js         Web Audio 合成的音效
│  ├─ shop.js          商店 UI、锁定、一键购买、快捷键
│  ├─ render.js        Canvas 渲染、子弹/粒子/特效、HUD、Boss 血条
│  └─ game.js         主循环、武器射击、敌/Boss AI、碰撞、伤害、波次流程
└─ .gitignore
```

## 运行

直接浏览器打开 `index.html` 即可，无需服务器。如需 localStorage 跨页面访问（数据看板），同源即可。
