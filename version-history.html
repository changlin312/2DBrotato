二、核心数值公式

敌人 HP 缩放 — enemyHpScale(wave)

v = 1 for w in 2..wave: if w == 11: v *= 3; continue # 第11波跳×3 if w == 21: v *= 3; continue # 第21波跳×3 if w <= 10: g = 0.15 # 早期温和 elif w <= 25: g = 0.30 # 中段高增长 else: g = max(0.10, 0.20 - (w-26)*0.04) # 末段减速到10% v *= 1 + g return v * 1.5^bossKilled # 击破Boss后全局×1.5

设计思路：分段增长率，让早期玩家熟悉 / 中段紧张 / 末段不爆炸。bossKilled 的 1.5× 给通过 boss 的隐性奖励。

Boss HP 缩放 — bossHpScale(wave)

base = enemyHpScale(wave) if wave == 10: base × 2 if wave == 20: base × 15 (×1.5 bossKilled) if wave == 30: base × 30 ÷ 2 (双 Boss 各半)

设计思路：第 10 波 boss 较弱让玩家尝 boss 战；第 20 波是中段硬关 (×15 配合 ×1.5)；第 30 波双 Boss 加强但单一血量减半，"压力共享但难复制"。

敌人伤害缩放

def.dmg × (1 + 0.05 × (wave - 1)) # 每波+5%线性

玩家武器成长

伤害 = base_dmg × 1.5^(tier-1) × dmgMult 冷却 = base_cd × 0.9^(tier-1) / atkSpd # atkSpd cap 2.0 射程 = base_range + (tier-1) × 20

武器伤害按 1.5^tier 指数增长，与敌人的 (1+g)^wave 增长呈竞速关系 — 玩家推阶快则秒杀，慢则卡壳。

金币奖励

击杀金币 = max(1, round(def.gold × (1 + 0.25×(wave-1)))) 波次通关奖金 = 8 + wave × 2 摇钱树年金 = wave × (10 + 5×(N-1)) N = 持有摇钱树数量

击杀金线性放大（不是指数），避免与道具叠加后失控；摇钱树线性，相对幸运草的乘法已被废弃。
